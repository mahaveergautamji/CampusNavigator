# Campus Compass

Campus Compass is a 3D campus navigation prototype made for Chhatrapati Shahu Ji Maharaj University (CSJMU), Kanpur. It helps students and visitors explore the campus, find buildings, and view routes to different locations.

## Features

- Interactive, game-inspired 3D campus
- Searchable building directory
- Route guidance with walking and auto modes
- Campus assistant for basic queries
- Accessibility and emergency information panels
- Day, sunset, and night viewing modes

## Tech Stack

React, TypeScript, Vite, Three.js, Tailwind CSS, and Lucide React.

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.

To create a production build:

```bash
npm run build
```

## Project Structure

- `src/components/` – UI and 3D campus components
- `src/data/csjmuData.ts` – campus buildings and information
- `src/utils/` – navigation, pathfinding, and other utilities
- `src/types/` – TypeScript types

## Note

This is a student project and is still a work in progress. Campus locations and routes are for demonstration and should be verified before relying on them.
